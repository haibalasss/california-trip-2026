# California Trip 2026

אפליקציית טיול: סן פרנסיסקו ← יוסמיטי ← מונטריי ← לוס אנג'לס, 20–26 בנובמבר 2026.

- `site/index.html` – האפליקציה. פרטי ההזמנות מוצפנים (AES-GCM, מפתח שנגזר מהסיסמה המשפחתית ב-PBKDF2). הסיסמה עצמה לא נשמרת בריפו.
- מזג אוויר חי נטען בדפדפן מ-[Open-Meteo](https://open-meteo.com/).
- `scripts/flights.mjs` – מושך גייט, טרמינל ועיכובים מ-AeroDataBox ושומר `flights.json`. רץ כל 20 דקות בימי הטיסות דרך GitHub Actions.

## הגדרה חד-פעמית
1. **Settings ← Pages ← Source: GitHub Actions**
2. **Settings ← Secrets and variables ← Actions ← New repository secret**: `AERODATABOX_KEY` (מפתח RapidAPI ל-AeroDataBox). בלי המפתח האתר עובד, רק בלי סטטוס טיסות.

## פרופיל הטעם של חי (לבקשות אוכל חיות)
לא המסעדות המפורסמות או היוקרתיות, אלא **מנות ספציפיות, יצירתיות ומפתיעות** עם אפקט WOW: טעמים חזקים, שילובים לא שגרתיים (מתוק-מלוח-חמוץ-חריף), מרקמים קריספיים, רטבים מעניינים, **ניגודים טרופיים של חמוץ-מתוק** (מנגו, אננס, ליים, פסיפלורה מול דג, בשר מעושן או חריף), אוכל רחוב מקומי, פיוז'ן, בשר איכותי ודגים. הטרופי הוא **עדיפות, לא חובה**: העיקר טעמים עזים או מיוחדים ומגוון סגנונות, ולא לרדד הכל לפוקה, סביצ'ה או קערות דג נא. **בלי פירות ים** (שרימפס, סרטנים, צדפות, קלאמס). דגים בסדר. פתוח לדוכנים ולמקומות פשוטים. להבדיל בין מנה טעימה באמת לבין מנה שרק יפה לאינסטגרם.
בכל המלצה: **שם המקום · שם המנה · למה היא מיוחדת (הסיבה הקונקרטית: טכניקה, מרקם, שילוב טעמים, ולא "מפורסם") · איך היא נראית**. 5–7 אפשרויות לכל אזור, כדי שתהיה בחירה. מתחילים מהמנות המיוחדות ביותר באזור, בלי המבורגרים, פיצות או מקומות תיירותיים גנריים.

## טיקטים של באגים
כפתור 🐞 בפינת המסך פותח טיקט. חובה לרשום מי פתח אותו. אף אחד לא צריך חשבון, ושום דבר לא נשלח לאף אחד.
1. הטלפון שומר את הטיקט בתיבה משותפת ב-ntfy.sh (שם הנושא ב-`site/bugs-db.json`, שומר הודעות כ-12 שעות). בלי אינטרנט הטיקט מחכה בטלפון ונשלח אוטומטית.
2. הפעולה `bugs-sync.yml` מעתיקה כל 15 דקות טיקטים חדשים ל-`site/bugs.json` בגיט, עם סטטוס `open`.
3. Claude קורא את הטיקטים מהגיט, מתקן, ומעדכן בקובץ `s` (`open|info|fixed|notabug|wont`), `r` (תגובת המפתח), `fix` (מה תוקן) ו-`closed` (זמן סגירה, ISO). טיקט סגור נעלם מהרשימה באפליקציה 12 שעות אחרי `closed`. הגיט קובע את הסטטוס, והתיבה רק מוסיפה טיקטים.

### איך Claude עונה על טיקטים
Claude עונה כמו מפתח קשוח שמתווכח עם ה-QA. הוא לא מקבל טיקט כבאג עד שהוא משחזר אותו בעצמו בקוד או בדפדפן.
טיקט עמום מקבל `s: "info"` עם שאלות חדות: באיזו לשונית, מה לחצו, מה ציפו שיקרה ומה קרה בפועל.
מה שעובד כמו שתוכנן מקבל `s: "notabug"` עם הסבר. רק באג ששוחזר מתוקן ומקבל `s: "fixed"` עם `fix`.
התגובה נכתבת בשדה `r` ומוצגת לכולם באפליקציה. בלי לשלוח הודעות לחי.

## לשונית דרך
- **טריוויה, מכונית מול מכונית:** כל משפחה היא מכונית, ו-20 שאלות מופיעות ב-`site/road.js` (`QUIZ`, התשובה הנכונה תמיד ראשונה במערך ומוצגת מעורבבת). התשובה הראשונה של כל מכונית נחשבת.
- **בינגו דרכים:** לוח 4×4 לכל מכונית ולכל יום. בינגו נשלח למכונית השנייה.
- הסנכרון בין המכוניות עובר דרך נושא ntfy.sh (`ROAD_TOPIC`). בלי קליטה הכל נשמר בטלפון ונשלח כשהקליטה חוזרת.

## הורדה מראש (prefetch.js)
פעם ביום, בחיבור הראשון, האפליקציה מורידה בשקט את התמונות של היום ושל מחר, את ספריית המפה ואריחי מפה סביב העצירות.
היא מתחילה 6 שניות אחרי הטעינה, בזמן פנוי, בקשה אחת בכל פעם, בעדיפות נמוכה. היא לא רצה בחיבור איטי או במצב חיסכון בנתונים.

## לשונית משחקים: חיפוש הטבע ביוסמיטי
- 30 דברים לחפש (`HUNT` ב-`site/nature.js`, הסדר חלק משמות הקבצים: רק מוסיפים בסוף), עם כוכבים לפי קושי. בלי טבלת ניקוד. רק התקדמות וכוכבים לקבוצה כולה.
- ילד בוחר את השם שלו, מצלם ומעלה. התמונה מוקטנת בטלפון (וכך נמחק ממנה המיקום) ונשלחת כקובץ מצורף לנושא ntfy.sh. בלי קליטה היא מחכה בטלפון ונשלחת כשיש.
- `games-sync.yml` רץ כל 15 דקות ומעתיק תמונות ל-`site/nature/` (הקובץ המצורף בשירות נמחק אחרי 3 שעות), ומגבה את אירועי הבינגו והטריוויה ל-`site/road-archive.json` (רק מוסיף, לא מוחק).
- מחיקת תמונה: מי שהעלה אותה, או מי שיודע את הסיסמה המשפחתית.
- הלשונית נפתחת ב-14:30 ב-22.11 (`NAT_OPEN`). לשונית הבגדים מוסתרת בהערה ב-`index.html`, והקוד שלה נשאר ב-`app.js`.

### ציוני חיפוש הטבע
`site/nature/review.json` מכיל לכל תמונה ציון (`s`, בקפיצות חצי כוכב, עד מספר הכוכבים של הדבר) ותגובה (`c`). הטבלה מחושבת באפליקציה: לכל ילד ולכל דבר נספר רק הציון הגבוה ביותר. הציונים והתגובות נחשפים ב-`NAT_RESULTS_AT` (20:00 ב-23.11). תמונה שנוספה אחרי הבדיקה מופיעה בלי ציון, ומוסיפים אותה לקובץ בהרצה חוזרת בלי לשנות ציונים קיימים.
